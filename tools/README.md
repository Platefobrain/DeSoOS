# tools – host tools for real hardware

Python 3 only, no extra packages (except `fontgen.py`, which needs fontTools – only to change the font); they write only the target named on the command line (`abigen.py`: only the generated files and a new lock in the repository).

| File | What |
|---|---|
| `abigen.py` | the ABI tool (`docs/abi/README.md`): checks `abi/abi.toml`, generates `docs/abi/SYSCALLS.md`, `sdk/libdeso/src/abi.rs` (the library's constants) and `kernel/user/abi_generated.rs` (no options), `--check` (the locks, the description, the generated files, the kernel's syscall numbers and argument registers, no hand-made constant in the library, every test and order reference in `abi.toml` exists – nothing written), `--test` (that + 25 mutations – what `tests/test.sh` runs), `--new-lock` (`abi/abi-<version>.lock`, only when it does not exist and every older lock passes); its own small TOML reader, so Python 3.10 is enough |
| `desopkg.py` | desopkg on the host (`docs/pkg/FORMAT.md`; Python 3 + `openssl`): `pack DIR -o x.pkg` (from `desopkg.meta`, `bin/`, `share/`), `index REPODIR --serial N --key K.pem` (`index` + `index.sig` from `packages/*.pkg`, low-S), `keys K.pem --keyid ID` (the `/etc/desopkg/keys` file – the public point only), `check FILE` (an independent check of any desopkg file), `vectors` (the PKG FORMAT TEST vectors – `build.sh --selftest`), `--test` (every rule on its own, the reserved names, pack → index → check – what `tests/test.sh` runs). The private key never goes into the repository |
| `fontgen.py` | the console font: reads the pixel font `kernel/drivers/DeSoConsole-Regular.ttf` (64-unit pixels on an 8x16 cell, refuses a glyph off that grid) and writes `kernel/drivers/font.rs`; `--check` only compares. The build uses `font.rs`, not the TTF |
| `mkusb.py` | the layout of a DeSo OS USB stick with a disk – called by `make-usb.sh --with-disk` (after its safety checks) and, for an image file, by `make-usb.sh --with-disk --image`, `tests/test.sh` and `tests/make-usb-test.sh`: GPT (protective MBR, both headers with CRC32), partition 1 = ESP (128 MiB, FAT32 `DESO` with `EFI/BOOT/BOOTX64.EFI`), partition 2 = "DeSo system" (`1A0E2E7D-DE32-4C13-9442-9FCB2649CA02`, the rest, at most 64 GiB) with an empty DeSoFS; the old tables cleared first, the GPT written last, then everything read back (caches dropped). A device is opened with `O_EXCL` and must still have the major:minor (of the open descriptor), size and serial number (the udev record of that major:minor, as lsblk shows it) `make-usb.sh` asked about – a missing or unclear serial is refused; 512-byte sectors only |
| `mkdesofs.py` | an empty DeSoFS volume (format 1, `docs/desofs/FORMAT.md` chapter 14) – the same bytes as the kernel's `desofs format` (DESOFS TEST compares them through `tests/mkdesofs.py --format`); random uuid and the current time unless given; writes only the blocks of the format in the kernel's order; refuses over 64 GiB or under 64 blocks. The command line formats **image files only** (a new one with `--blocks`, an existing non-empty one with `--force`); a device or a link to one is refused, also with `--force` – a stick gets its DeSoFS from `make-usb.sh --with-disk` |
