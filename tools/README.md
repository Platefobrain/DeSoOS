# tools – host tools for real hardware

Python 3 only, no extra packages; they write only the target named on the command line (`abigen.py`: only the generated files and a new lock in the repository).

| File | What |
|---|---|
| `abigen.py` | the ABI tool (`docs/abi/README.md`): checks `abi/abi.toml`, generates `docs/abi/SYSCALLS.md`, `user/lib/abi_generated.rs` and `kernel/user/abi_generated.rs` (no options), `--check` (the locks, the description, the generated files, the kernel's syscall numbers and argument registers, the library's constants – nothing written), `--test` (that + 18 mutations – what `tests/test.sh` runs), `--new-lock` (`abi/abi-<version>.lock`, only when it does not exist and every older lock passes); its own small TOML reader, so Python 3.10 is enough |
| `mkusb.py` | the layout of a DeSoOS USB stick with a disk – called by `make-usb.sh --with-disk` (after its safety checks) and, for an image file, by `make-usb.sh --with-disk --image`, `tests/test.sh` and `tests/make-usb-test.sh`: GPT (protective MBR, both headers with CRC32), partition 1 = ESP (128 MiB, FAT32 `DESOOS` with `EFI/BOOT/BOOTX64.EFI`), partition 2 = "DeSoOS system" (`1A0E2E7D-DE32-4C13-9442-9FCB2649CA02`, the rest, at most 64 GiB) with an empty DeSoFS; the old tables cleared first, the GPT written last, then everything read back (caches dropped). A device is opened with `O_EXCL` and must still have the major:minor (of the open descriptor), size and serial number (the udev record of that major:minor, as lsblk shows it) `make-usb.sh` asked about – a missing or unclear serial is refused; 512-byte sectors only |
| `mkdesofs.py` | an empty DeSoFS volume (format 1, `docs/desofs/FORMAT.md` chapter 14) – the same bytes as the kernel's `desofs format` (DESOFS TEST compares them through `tests/mkdesofs.py --format`); random uuid and the current time unless given; writes only the blocks of the format in the kernel's order; refuses over 64 GiB or under 64 blocks. The command line formats **image files only** (a new one with `--blocks`, an existing non-empty one with `--force`); a device or a link to one is refused, also with `--force` – a stick gets its DeSoFS from `make-usb.sh --with-disk` |
